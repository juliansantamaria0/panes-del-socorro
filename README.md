# Panes del Socorro

Sitio web de Panes del Socorro, construido con HTML, CSS y JavaScript.

## Ver el sitio

Abre `index.html` en un navegador. No requiere instalación ni compilación.

## Archivos

- `index.html`: contenido del sitio.
- `estilos.css`: estilos y diseño adaptable.
- `app.js`: interacciones del sitio.
- `img/`: imágenes y logotipo.
- `video/`: video del local.
